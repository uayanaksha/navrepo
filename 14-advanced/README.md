# 14 — Advanced

> The earlier sections get you contributing well. This one is for when
> you're the reviewer, the mentor, the person debugging the production
> incident, and the engineer others rely on.

These are the skills that show up once you've been around a while:
giving review instead of just receiving it, operating in monorepos and
distributed systems, taming legacy code, deep debugging and performance
work, reading the papers behind the systems, and building a reputation
that compounds.
