# 03 — Reading Code

> Reading is a separate skill from writing — and the one you'll do more
> of, every single day.

Top engineers read 10x more code than they write. This section is about
making your reading faster, deeper, and less exhausting.

## The One-Sentence Summary

> **Don't read everything. Read the right things, in the right order,
> and tolerate not understanding until you do.**
